## ASCII File & Folder Structure
```
└── Python Bakery/                      # Root Folder
    ├── personal/                       # User Inventory
    │   └── wallet.json                 # User Wallet
    ├── city/                           # Outdoor City
    │   ├── supermarkets/               # Supermarkets
    │   │   ├── healthfood_store.py
    │   │   └── regular_supermarket
    |   ├── select_location.py
    |   ├── bank.py
    │   └── police_station.py
    ├── utensils/                       # Utensils for Bakery
    │   ├── large_mixing_bowl.py
    │   └── baking_pan.py
    ├── bake.py
    ├── oven.py
    ├── start.py                        # Run this to start the game
    ├── pantry.json                     # User Pantry
    ├── pantryCheck.py
    └── recipe.json                     # Cake Recipe
```
