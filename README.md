## Story

You own a bakery somewhere in the city, which is also your home because you are homeless. You want to bake a **Chocolate Nutella Cake**, but you have no money, need to work and buy the ingredients to bake the cake. Are you willing to play this game and star it? Please do it for me, because I spent quite some time programming this useless game... 

~ Pikachu Dev

---

## Installation Guide

1. **Download Latest Release:** From the Releases section, download the latest release for a stable and updated game version.
2. **Python 3.15.1:** Make sure you have Python 3.15.1 or higher installed. [Click here to download Python.](https://www.python.org/downloads/)
4. **Run `start.py`:** To play the game, run `start.py` in the root folder.
